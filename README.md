# DT Prosthetic Care — Don Tum Hospital

ต้นแบบเว็บไซต์สำหรับโรงงานทำขาเทียมพระราชทาน โรงพยาบาลดอนตูม เปิดจากปุ่มเมนูใน LINE Official Account ได้โดยใช้ URL ของเว็บไซต์

## ฟังก์ชันต้นแบบ

- แบบฟอร์มขอคิวนัดและแบบประเมินความพร้อมเบื้องต้น
- เลือกรูปตอขา 3 มุม (หน้า / ข้าง / หลัง) พร้อมแสดงตัวอย่างภาพบนเครื่อง
- เจ้าหน้าที่ดูรายการสาธิต กำหนดวันนัด และเปลี่ยนสถานะ
- ผู้ป่วยดูสถานะและวันนัดจากหน้าเว็บด้วยรหัสคำขอจำลอง
- คู่มือดูแลตอขาและท่าออกกำลังกายเพื่อให้บุคลากรตรวจทานก่อนใช้จริง
- แบบติดตามหลังได้รับขาเทียม

## ขอบเขตความปลอดภัยของเวอร์ชันนี้

**โปรเจกต์นี้เป็น DEMO เท่านั้น ห้ามใช้ข้อมูลผู้ป่วยจริง** ไม่มีฐานข้อมูลหรือ API รับข้อมูล ตัวอย่างคำขอจะอยู่ในหน่วยความจำของแท็บเบราว์เซอร์และหายไปเมื่อรีโหลด ภาพที่เลือกแสดงด้วย `URL.createObjectURL` เฉพาะเครื่องและไม่ส่งไปยังเซิร์ฟเวอร์ การเปลี่ยนสถานะโดยเจ้าหน้าที่เป็นการจำลองภายในแท็บเดียวกัน ไม่ใช่สิทธิ์ผู้ใช้งานจริง

ห้ามเปิดรับข้อมูลสุขภาพจริงบน GitHub Pages เพียงอย่างเดียว: ต้องมีบริการหลังบ้านที่มีการยืนยันตัวตนและสิทธิ์เข้าถึงข้อมูลรายผู้ป่วย, ฐานข้อมูลส่วนตัว, พื้นที่จัดเก็บภาพแบบไม่สาธารณะ, บันทึกการเข้าถึง, นโยบายเก็บและลบข้อมูล และการทบทวนมาตรการ PDPA โดยโรงพยาบาล

## เริ่มใช้งาน DEMO

เปิด `index.html` หรือให้บริการเป็น static site (`python3 -m http.server 8000`) จากโฟลเดอร์นี้ ไม่ต้องติดตั้ง dependency

## ขึ้น GitHub Pages

1. สร้าง repository ใหม่บน GitHub เช่น `dontum-prosthetic-care` (แนะนำ Private ระหว่างพัฒนา)
2. Push ไฟล์ในโฟลเดอร์นี้ขึ้น branch `main`
3. หากต้องการหน้า DEMO สาธารณะให้ตั้ง Settings → Pages → Build and deployment → Deploy from a branch → `main` / root แล้วนำ URL ไปใส่ปุ่ม URL ใน Rich Menu ของ LINE OA
4. **ห้ามใช้งานจริงกับข้อมูลผู้ป่วย** จนกว่าระบบหลังบ้านและการตรวจสอบความปลอดภัยจะเสร็จ

## แนวทางต่อยอดระบบจริง

- ผู้ป่วยยืนยันตัวตนผ่าน LINE Login / LIFF ร่วมกับการผูกตัวตนที่โรงพยาบาลยืนยันแล้ว (อย่าใช้ LINE ID หรือ HN เพียงอย่างเดียวเป็นหลักฐานสิทธิ์)
- บริการ API ที่ตรวจสิทธิ์ทุกคำขอด้วย session และ role `PATIENT`, `PROSTHETIST`, `PT`, `ADMIN`
- จัดเก็บแบบประเมินและนัดหมายในฐานข้อมูลที่จำกัดสิทธิ์; เก็บรูปใน private object storage และเสิร์ฟผ่าน URL อายุสั้น
- แสดงเฉพาะสถานะทั่วไปในหน้า LINE ไม่ส่งรายละเอียดสุขภาพไปในข้อความแจ้งเตือน
- เจ้าหน้าที่ต้องตรวจสอบความพร้อมก่อนกดนัดหมาย และแก้ไขวันนัดพร้อมประวัติการเปลี่ยนแปลง
- แบบติดตามหลังรับขาเทียม 7 วัน / 1 เดือน / 3 เดือน / 6 เดือน เป็นค่าเริ่มต้นที่หน่วยงานปรับได้
